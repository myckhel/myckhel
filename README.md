## Featured work

### Skilled Task Executor

**From task to tested change.**

A tool-agnostic coding-agent skill for executing software development tasks from connected task-management platforms. It gives agents a workflow for finding tasks, understanding requirements, implementing changes, validating results, and preparing a traceable handoff.

[![Agent skill](https://img.shields.io/badge/FORMAT-Agent_Skill-2563EB?style=flat-square)](https://github.com/myckhel/skilled-task-executor)
[![MCP tools](https://img.shields.io/badge/ACCESS-MCP_Tools-0F766E?style=flat-square)](https://github.com/myckhel/skilled-task-executor/blob/main/references/capability-contract.md)
[![Execution modes](https://img.shields.io/badge/MODES-Interactive_%2F_Autonomous_%2F_Review-E76F51?style=flat-square)](https://github.com/myckhel/skilled-task-executor#choose-your-mode)
[![skills.sh](https://skills.sh/b/myckhel/skilled-task-executor)](https://skills.sh/myckhel/skilled-task-executor)

```sh
npx skills add myckhel/skilled-task-executor --skill skilled-task-executor
```

- **Start with your tracker.** List, search, and read tasks through connected MCP tools.
- **Keep work accountable.** Carry requirements, validation results, and task references through the implementation.
- **Choose the pace.** Work interactively, authorize an autonomous run, or request a read-only review.
- **Respect the integration.** Use exposed connector tools and keep credentials inside the connector's authentication flow.

The skill defines the workflow; your coding agent and connected tools execute it. Platform examples include Asana, Linear, Jira, and other compatible MCPs.
